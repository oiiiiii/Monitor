### 问题分析与解决方案
#### 问题1：波形绘制时间短
当前方案中 `MAX_WAVE_POINTS = 600`（200Hz采样率下仅3秒），若需要更长显示时间，需调整缓冲长度并适配Canvas绘制逻辑。

#### 问题2：绘制方向与滚动逻辑错误
原逻辑是**从右向左滚动**（新数据在右侧），需改为**从左向右绘制**，画布填满后从左侧覆盖，旧数据随新数据绘制同步从右侧消失（符合医疗监护仪标准模式）。

### 具体修改步骤，以下代码仅供参考，可能与项目不符。

#### 1. 调整波形数据缓冲配置（stores/bed.ts）
```typescript
// 按需调整显示时长，例如改为10秒（200Hz * 10 = 2000点）
const MAX_WAVE_POINTS = 2000 // 原600点 → 可配置化，支持更长时间显示

// 数据更新逻辑保持循环缓冲，但数组存储顺序改为「新数据追加到末尾」（关键）
function updateWave(wave: WaveformData) {
  const existing = bed.waves[lead]
  if (!existing) {
    // 新导联：初始化时直接存入（限制长度）
    const samples = wave.samples.slice(-MAX_WAVE_POINTS)
    bed.waves[lead] = { ...wave, samples }
  } else {
    // 追加新样本到数组末尾，保持固定长度（循环缓冲）
    const newSamples = [...existing.samples, ...wave.samples]
    // 超出长度时，从头部截断（保留最新的MAX_WAVE_POINTS个点）
    existing.samples = newSamples.length > MAX_WAVE_POINTS 
      ? newSamples.slice(-MAX_WAVE_POINTS) 
      : newSamples
  }
  triggerRef(beds)
}
```

#### 2. 核心修改：WaveformCanvas.vue 绘制逻辑
```vue
<template>
  <canvas ref="canvas" class="waveform-canvas"></canvas>
</template>

<script setup lang="ts">
import { ref, watch, onMounted, onUnmounted, shallowRef } from 'vue'

const props = defineProps<{
  samples: number[]
  color: string
  leadName: string
  speed?: number
  gain?: number
}>()

const canvas = ref<HTMLCanvasElement | null>(null)
const gridSize = ref(10)
const DPR = window.devicePixelRatio || 1
let animationId: number | null = null
let lastSamplesLength = ref(0)

// 配置项：可根据需求调整
const POINTS_PER_PIXEL = 2 // 每像素显示的采样点数
const DISPLAY_POINTS = ref(0) // 画布可显示的点数（动态计算）

// 调整Canvas尺寸并计算可显示点数
function resizeCanvas() {
  if (!canvas.value) return
  const rect = canvas.value.getBoundingClientRect()
  
  // 高分辨率适配
  canvas.value.width = Math.floor(rect.width * DPR)
  canvas.value.height = Math.floor(rect.height * DPR)
  
  // 计算画布可显示的采样点数（核心：决定单屏显示范围）
  DISPLAY_POINTS.value = Math.floor(canvas.value.width * POINTS_PER_PIXEL)
  gridSize.value = Math.floor(Math.min(rect.width, rect.height) / 50) || 10
  
  // 尺寸变化时触发重绘
  scheduleDraw()
}

// 绘制网格（保持原有逻辑，仅适配坐标）
function drawGrid(ctx: CanvasRenderingContext2D, w: number, h: number) {
  ctx.clearRect(0, 0, w, h) // 清空画布
  const smallGrid = gridSize.value
  const bigGrid = smallGrid * 5

  // 绘制小网格（浅灰色）
  ctx.strokeStyle = 'rgba(80, 80, 80, 0.15)'
  ctx.lineWidth = 0.5
  for (let x = 0; x <= w; x += smallGrid) {
    ctx.beginPath()
    ctx.moveTo(x, 0)
    ctx.lineTo(x, h)
    ctx.stroke()
  }
  for (let y = 0; y <= h; y += smallGrid) {
    ctx.beginPath()
    ctx.moveTo(0, y)
    ctx.lineTo(w, y)
    ctx.stroke()
  }

  // 绘制大网格（深灰色）
  ctx.strokeStyle = 'rgba(100, 100, 100, 0.2)'
  ctx.lineWidth = 1
  for (let x = 0; x <= w; x += bigGrid) {
    ctx.beginPath()
    ctx.moveTo(x, 0)
    ctx.lineTo(x, h)
    ctx.stroke()
  }
  for (let y = 0; y <= h; y += bigGrid) {
    ctx.beginPath()
    ctx.moveTo(0, y)
    ctx.lineTo(w, y)
    ctx.stroke()
  }
}

// 核心：重写波形绘制逻辑（从左到右，满屏后覆盖）
function drawWaveform(ctx: CanvasRenderingContext2D, w: number, h: number) {
  const samples = props.samples
  if (!samples || samples.length < 2) return // 数据不足时跳过

  // 1. 计算显示窗口：
  // - 总缓冲数据：samples（新数据在末尾）
  // - 单屏可显示点数：DISPLAY_POINTS.value
  // - 绘制逻辑：
  //   - 未填满屏：从索引0开始绘制到当前长度
  //   - 填满屏：取最后DISPLAY_POINTS个点（新数据在右侧，覆盖左侧旧数据）
  const startIdx = samples.length > DISPLAY_POINTS.value 
    ? samples.length - DISPLAY_POINTS.value 
    : 0
  const displaySamples = samples.slice(startIdx)

  // 2. 动态范围自适应（保持原有逻辑）
  let minVal = displaySamples[0]
  let maxVal = displaySamples[0]
  for (const val of displaySamples) {
    if (val < minVal) minVal = val
    if (val > maxVal) maxVal = val
  }
  const range = maxVal - minVal || 1 // 防止除零

  // 3. 波形绘制参数
  const midY = h / 2
  const amplitude = h * 0.35 // 波形振幅（占画布70%高度）
  ctx.strokeStyle = props.color || '#00ff00'
  ctx.lineWidth = 1.5 * DPR // 适配高分辨率
  ctx.beginPath()

  // 4. 从左到右绘制（核心修改）
  let started = false
  for (let i = 0; i < displaySamples.length; i++) {
    // X轴：从左到右（i=0 → x=0，i=displaySamples.length → x=画布宽度）
    const x = (i / POINTS_PER_PIXEL) * DPR // 适配DPR
    
    // Y轴：归一化（保持原有逻辑，翻转Y轴符合心电图惯例）
    const val = displaySamples[i] || 0
    const normalized = ((val - minVal) / range) * 2 - 1 // [-1, 1]
    const y = midY - normalized * amplitude

    if (!started) {
      ctx.moveTo(x, y)
      started = true
    } else {
      ctx.lineTo(x, y)
    }
  }
  ctx.stroke()
}

// 绘制入口
function draw() {
  if (!canvas.value) return
  const ctx = canvas.value.getContext('2d')
  if (!ctx) return

  const w = canvas.value.width
  const h = canvas.value.height

  // 步骤1：清空画布（全量重绘）
  ctx.fillStyle = '#0a0a0a' // 医疗监护仪深色背景
  ctx.fillRect(0, 0, w, h)

  // 步骤2：绘制网格
  drawGrid(ctx, w, h)

  // 步骤3：绘制波形
  drawWaveform(ctx, w, h)
}

// 防抖+requestAnimationFrame优化
function scheduleDraw() {
  if (animationId) return
  animationId = requestAnimationFrame(() => {
    animationId = null
    draw()
  })
}

// 监听数据变化（仅监听长度，避免深度比较）
watch(
  () => props.samples.length,
  (newLen) => {
    if (newLen !== lastSamplesLength.value) {
      lastSamplesLength.value = newLen
      scheduleDraw()
    }
  }
)

// 生命周期
onMounted(() => {
  resizeCanvas()
  window.addEventListener('resize', resizeCanvas)
  scheduleDraw()
})

onUnmounted(() => {
  window.removeEventListener('resize', resizeCanvas)
  if (animationId) cancelAnimationFrame(animationId)
})
</script>

<style scoped>
.waveform-canvas {
  width: 100%;
  height: 100%;
  display: block;
  background-color: #0a0a0a;
}
</style>
```

### 关键修改说明
#### 1. 波形绘制时间短问题解决
- 调整 `MAX_WAVE_POINTS`：根据采样率计算所需显示时长（如200Hz采样率下，10秒需2000点，30秒需6000点）。
- 注意：点数越多，内存占用越高，需根据前端性能平衡（建议单导联不超过6000点，多导联可分批次渲染）。

#### 2. 绘制方向与滚动逻辑修改（核心）
| 原逻辑 | 新逻辑 |
|--------|--------|
| 新数据追加到右侧，从右向左绘制 | 新数据追加到数组末尾，从左向右绘制 |
| 超出长度时截断头部 | 超出单屏显示点数时，取最后N个点（模拟「覆盖左侧」效果） |
| 旧数据向左滚动消失 | 画布填满后，新数据从左侧覆盖，旧数据随绘制点右移同步消失 |

#### 3. 额外优化
- **DPR适配增强**：线宽、坐标计算均乘以DPR，避免高分辨率屏幕模糊。
- **配置解耦**：`DISPLAY_POINTS` 动态计算（基于画布宽度），适配不同尺寸的Canvas。
- **性能保持**：保留 `requestAnimationFrame` + 防抖，避免频繁重绘。

### 验证与调优
1. **时间长度验证**：修改 `MAX_WAVE_POINTS` 后，可通过 `samples.length` 确认缓冲数据量，结合采样率计算显示时长（时长 = 总点数 / 采样率）。
2. **绘制方向验证**：观察新数据是否从左侧开始绘制，画布填满后是否从左侧覆盖，旧数据从右侧同步消失。
3. **性能调优**：若点数过多导致卡顿，可降低 `POINTS_PER_PIXEL`（如改为1），或开启Canvas离屏渲染。

### 扩展建议
- **配置化**：将 `MAX_WAVE_POINTS`、`POINTS_PER_PIXEL`、显示时长等参数抽离到配置文件，支持动态调整。
- **多导联同步**：若需多导联同时显示，可统一缓冲长度，保证时间轴对齐。
- **帧率控制**：医疗监护仪通常要求25/30fps，可通过 `setInterval` 结合 `requestAnimationFrame` 限制绘制频率（避免过高帧率占用资源）。
