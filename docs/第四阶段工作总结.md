## 工作内容

### 1. 模块架构设计

基于项目「零丢包、分层解耦」的架构原则，消息缓冲层实现了：
- RabbitMQ 作为核心消息中间件
- 4 个独立队列按数据类型解耦
- 本地磁盘兜底缓存作为降级方案
- 接入层与 MQ 之间通过数据管道层集成

### 2. MQ 模块（monitor-common/src/mq/）

#### 2.1 配置管理 [config.rs](file:///d:/Code/Monitor/monitor-common/src/mq/config.rs)
- 支持环境变量配置（`MONITOR_MQ_` 前缀）
- 连接参数：主机、端口、用户名、密码、虚拟主机
- 可靠性参数：确认超时、最大重试次数、重试间隔
- 消费者参数：预取数量

#### 2.2 队列定义 [queues.rs](file:///d:/Code/Monitor/monitor-common/src/mq/queues.rs)

**符合项目规范的 4+1 队列架构：**

| 队列名 | 路由键 | 用途 |
|--------|--------|------|
| `ecg_wave` | `ecg.wave` | 波形数据 |
| `ecg_vital` | `ecg.vital` | 生命体征数据 |
| `ecg_alarm` | `ecg.alarm` | 报警事件 |
| `ecg_raw` | `ecg.raw` | 原始报文 |
| `ecg_dead_letter` | `#` | 死信队列 |

**交换机设计：**
- 主交换机：`ecg_exchange`（topic 类型）
- 死信交换机：`ecg_dead_letter_exchange`（direct 类型）
- 所有业务队列绑定死信交换机，消费失败的消息自动转入死信

**可靠性保障：**
- ✅ 队列持久化（durable）
- ✅ 消息持久化（delivery_mode = 2）
- ✅ 死信队列配置

#### 2.3 生产者实现 [producer.rs](file:///d:/Code/Monitor/monitor-common/src/mq/producer.rs)

**核心特性：**
- **Publisher Confirm 机制**：每条消息等待 Broker 确认，确保不丢
- **失败重试**：默认重试 3 次，间隔 1 秒
- **自动重连**：连接断开后后台自动尝试重连
- **线程安全**：Arc<Mutex> 包装，可跨任务共享

**发送流程：**
```
获取通道 → 检查连接 → 发送消息 → 等待 Confirm → 成功/失败重试
                          ↓ 连接断开
                      触发自动重连
```

### 3. 本地磁盘兜底缓存（monitor-common/src/buffer/）

#### 功能实现 [mod.rs](file:///d:/Code/Monitor/monitor-common/src/buffer/mod.rs)

**设计目标**：MQ 不可用时不丢任何数据，恢复后自动补发。

**存储格式：**
- 按日期分文件（`YYYYMMDD.buf`）
- 单文件超过 64MB 自动切换
- 单条消息：[4字节长度前缀][JSON 元数据][payload]
- 元数据包含：队列类型、设备 IP、时间戳

**核心功能：**
- 消息写入：带长度前缀的二进制格式，支持顺序追加
- 消息读取：扫描所有 .buf 文件，按时间顺序读取
- 消费模式：读取成功后删除文件，避免重复消费
- 容量控制：总大小上限 2GB，超过后拒绝写入

**自动补发机制：**
- MQ 重连成功后自动触发补发
- 补发成功才删除缓存文件
- 补发失败的消息保留，下次继续尝试

### 4. 数据管道集成（monitor-access/src/pipeline.rs）

#### 功能实现 [pipeline.rs](file:///d:/Code/Monitor/monitor-access/src/pipeline.rs)

**职责**：作为接入层与 MQ/缓冲之间的中间层，封装发送逻辑。

**发送路由：**
```
接入事件 → 按类型序列化 → 尝试 MQ 发送
                    ↓ 失败
               写入磁盘缓冲
                    ↓ MQ 恢复
                 自动补发
```

**事件到队列映射：**
- `VitalSignsReceived` → `ecg_vital` 队列
- `WaveformReceived` → `ecg_wave` 队列
- `AlarmReceived` → `ecg_alarm` 队列

**后台任务：**
- MQ 重连任务（每 5 秒尝试重连）
- 缓存补发任务（重连成功后自动触发）
