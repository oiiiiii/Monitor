## 五、波形数据解析规范

### 5.1 迈瑞波形解析

**输入数据：**
```
-64^-80^-92^-96^-96^-88^-68^-36^4^56^108^152^...
```

**解析步骤：**
1. 按 `^` 分割字符串，得到整数数组
2. 每个值乘以分辨率 0.001221 mV，得到实际电压值
3. 例如：-64 × 0.001221 = -0.0781 mV

**电压范围估算：**
- 数据值范围：约 -1000 到 +1000
- 电压范围：约 -1.22 mV 到 +1.22 mV

### 5.2 科曼波形解析

**输入数据：**
```
2046^2046^2046^2046^2046^2046^...
```

**解析步骤：**
1. 按 `^` 分割字符串，得到整数数组
2. 减去基线值 2046，得到偏移量
3. 乘以增益系数（需根据设备规格确定）

**电压范围估算：**
- 数据值范围：0-4095（12位ADC）
- 基线：2046
- 偏移范围：-2046 到 +2049

## 七、注意事项

1. **时区处理**：科曼使用UTC时间（+0000），迈瑞使用北京时间（+0800），解析时需统一转换
2. **编码兼容性**：所有设备均使用UTF-8编码，中文支持良好
3. **迈瑞私有编码**：需维护 `99MNDRY` 命名空间的编码映射表
4. **设备能力检测**：同一型号设备可能配置不同传感器，需动态检测可用参数
5. **波形数据量**：迈瑞每帧约500个采样点/导联（500Hz），科曼每帧约250个采样点/导联（250Hz），6导联总计3000/1500个点/秒
6. **迈瑞波形属性差异**：两个迈瑞设备使用不同的MDC代码表示采样率和INOP状态，解析时需兼容两种代码
7. **报警消息**：迈瑞使用ORU_R40消息类型发送报警，需独立处理该消息类型
8. **报警优先级**：H=高优先级，PM=中优先级，PL=低优先级，需根据优先级采取不同的UI展示策略
