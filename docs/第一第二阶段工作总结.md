# 多床位心电监护系统 - 阶段一 & 阶段二 工作总结

## 项目概述

基于 Rust 开发的多床位心电监护系统，支持科曼（Comen）和迈瑞（Mindray）监护仪的 HL7 v2.6 协议解析，实现生命体征、波形数据、报警事件的实时采集与标准化输出。

## 阶段二：HL7 协议解析模块 ✅

### 完成时间
2026-06-26

### 工作内容

#### 1. 帧解析器 ([frame.rs](file:///d:/Code/Monitor/monitor-proto/src/frame.rs))
- **帧边界检测**：`\x0B`（VT）帧头 + `\x1C\x0D`（FS+CR）帧尾
- **流式解析**：支持分片数据、粘包处理
- **缓冲区管理**：自动处理不完整帧，等待后续数据
- **垃圾数据过滤**：自动丢弃帧间无效数据

#### 2. 段解析器 ([segments.rs](file:///d:/Code/Monitor/monitor-proto/src/segments.rs))
- **MSH 段**：消息头（发送方、消息类型、版本、时间）
- **OBR 段**：观测请求（服务ID、观测时间）
- **OBX 段**：观测结果（值类型、观测ID、值、单位、状态）
- **日期时间解析**：支持多种 HL7 时间格式（含/不含毫秒、含/不含时区）
- **容错处理**：OBX 段最少 6 个字段即可解析，后续字段可选

#### 3. 生命体征解析 ([vital.rs](file:///d:/Code/Monitor/monitor-proto/src/vital.rs))
- 支持参数：心率、脉率、无创血压（收缩/舒张/平均）、有创血压、血氧饱和度、呼吸率、体温等
- 双厂商兼容：迈瑞 MDC 编码 + 科曼私有编码
- 自动识别设备厂商并路由对应解析逻辑

#### 4. 波形数据解析 ([waveform.rs](file:///d:/Code/Monitor/monitor-proto/src/waveform.rs))
- **采样率**：迈瑞 500Hz / 科曼 250Hz（从 MDC_ATTR_SAMP_RATE OBX 读取）
- **导联支持**：I、II、III、aVR、aVL、aVF、V1~V6 等
- **数据格式**：NA 类型 `^` 分隔的采样点数组
- **INOP 标志**：无效波形检测

#### 5. 报警数据解析 ([alarm.rs](file:///d:/Code/Monitor/monitor-proto/src/alarm.rs))
- **消息类型**：ORU_R40 报警消息
- **优先级**：H（高）/ PM（中）/ PL（低）
- **事件阶段**：开始（开始报警）/ 结束（报警解除）
- **触发参数**：触发报警的生命体征参数及值

#### 6. MDC 编码映射 ([mdc_codes.rs](file:///d:/Code/Monitor/monitor-proto/src/mdc_codes.rs))
- 标准 MDC 编码到参数名映射
- 厂商私有编码识别（99MNDRY / 99COMEN）
- 波形、采样率等特殊 OBX 识别

#### 7. 统一解析入口 ([parser.rs](file:///d:/Code/Monitor/monitor-proto/src/parser.rs))
- `Hl7Parser::parse()` 一站式解析
- 自动识别设备厂商
- 自动判断消息类型（生命体征 / 波形 / 报警）
- 输出标准化 `ParsedData` 枚举

## 技术亮点

1. **零拷贝解析**：大量使用 `&str` 切片，减少内存分配
2. **流式帧解析**：支持 TCP 流式数据的增量解析
3. **容错设计**：OBX 字段不足时优雅降级，不中断整体解析
4. **双厂商架构**：统一接口 + 厂商特化实现，易扩展新设备
5. **完整测试覆盖**：单元测试 + 真实日志集成测试双重验证
