# 第九阶段工作总结：科曼/迈瑞设备HL7数据解析修复

## 时间范围
2026-06-28

## 问题背景

用户反馈科曼监护仪的无创血压（NIBP）和灌注指数（PI）无法正常解析，日志文件位于 `D:\Code\Monitor\monitor_20260628_123717.log`。经过深入分析，发现科曼和迈瑞设备使用的 MDC 编码存在差异，导致部分数据无法被正确识别和解析。

## 问题分析过程

### 1. 日志分析

通过分析日志 `monitor_20260628_123717.log`，发现：
- 科曼设备（IP: 10.10.12.66，床位2）只解析出 HR，SpO₂ 显示为 None
- NIBP 和 PI 数据未出现在解析结果中

进一步分析 `log/1.log` 中的原始 HL7 报文：
- 科曼 NIBP 使用标准 MDC 编码（150021/150022/150023）
- 科曼只发送脉搏率（149546），不发送心率（147842）
- 日志中未发现科曼发送灌注指数数据

### 2. 参考代码研究

查看 `D:\Code\PCtools\Monitor\MonitorService\Program.cs` 中的 `AssignParameter` 方法（第807-878行），发现科曼和迈瑞设备编码的关键区别：

| 参数类型 | 科曼编码 | 迈瑞编码 |
|---------|---------|---------|
| NIBP收缩压 | 150021 | 150301 |
| NIBP舒张压 | 150022 | 150302 |
| NIBP平均压 | 150023 | 150303 |
| IBP收缩压 | 150033 | 150037 |
| IBP舒张压 | 150034 | 150038 |
| IBP平均压 | 150035 | 150039 |
| 呼吸率 | 151562 | 151578 |
| 灌注指数 | 150488/160324 | 150488/160324 |

### 3. 原解析器问题定位

`monitor-proto/src/vital.rs` 中存在的问题：
- NIBP 只支持标准 MDC 编码（150021/150022/150023），不支持迈瑞编码
- IBP MAP 缺少科曼编码 150035
- 灌注指数缺少备用编码 160324
- 心率字段只映射 147842，未处理脉搏率作为心率的场景

## 解决方案

### 1. 更新 vital.rs 解析器

修改 `monitor-proto/src/vital.rs` 第92-130行，扩展编码映射：

```rust
match code {
    // 心率
    "147842" => vital.heart_rate = int_val,

    // 呼吸率（多种编码兼容）
    "151578" | "151562" => vital.resp_rate = int_val,

    // 血氧饱和度
    "150456" => vital.spo2 = int_val,

    // 脉搏率（科曼设备只发送脉搏率，不发送心率，所以也映射到心率字段）
    "149530" | "149546" => {
        vital.pulse_rate = int_val;
        if vital.heart_rate.is_none() {
            vital.heart_rate = int_val;
        }
    }

    // 灌注指数（多种编码兼容）
    "150488" | "160324" => vital.pi = float_val,

    // 无创血压 - 科曼使用标准MDC编码，迈瑞使用150301/150302/150303
    "150021" | "150301" => vital.nibp_sys = int_val,
    "150022" | "150302" => vital.nibp_dia = int_val,
    "150023" | "150303" => vital.nibp_map = int_val,

    // 有创血压 - 科曼和迈瑞使用不同编码
    "150037" | "150033" => vital.ibp_sys = int_val,
    "150038" | "150034" => vital.ibp_dia = int_val,
    "150039" | "150035" => vital.ibp_map = int_val,

    // 室早率
    "148066" => vital.vpc_rate = int_val,

    _ => {
        tracing::debug!("未识别的 MDC 生命体征代码: {}", code);
    }
}
```

## 技术要点总结

### HL7 MDC 编码体系
- 标准 MDC 编码由 IEEE 11073 定义，理论上各厂商应统一使用
- 实际上迈瑞、科曼等厂商在部分参数上使用私有编码或不同的编码映射
- 解析器需要同时支持标准编码和厂商私有编码

### 设备行为差异
- **心率数据**：迈瑞发送心率（147842），科曼只发送脉搏率（149546）
- **NIBP 编码**：科曼使用标准 MDC，迈瑞使用私有编码（150301/150302/150303）
- **IBP 编码**：两个厂商使用完全不同的编码体系

### 数据完整性处理
- 当心率字段为空时，使用脉搏率填充
- 日志输出完整体征数据，便于调试和验证

## 后续建议

1. **持续监控**：建议在实际环境中测试，观察日志输出是否正确解析 NIBP 和 PI 数据
2. **灌注指数问题**：如果科曼设备仍无 PI 数据，可能需要检查监护仪配置，确认是否启用了灌注指数输出
3. **编码扩展**：如有其他厂商设备接入，可参考 `Program.cs` 的编码映射进行扩展
