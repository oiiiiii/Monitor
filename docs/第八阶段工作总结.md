## 二、完成内容

### 2.1 系统监控指标（metrics）

**文件**：`monitor-common/src/metrics/mod.rs`

#### 基础指标类型
- **Counter**：计数器（单调递增）
  - 总连接数、消息处理数、错误数等
- **Gauge**：仪表盘（可升可降）
  - 当前活跃连接数、队列长度等
- **RateMeter**：速率表
  - 消息吞吐率（QPS）

#### 服务指标
- **AccessMetrics**：接入层指标
  - `connections_total`：总连接数
  - `connections_active`：活跃连接数
  - `frames_received`：接收帧数
  - `bytes_received`：接收字节数
  - `messages_parsed`：解析消息数
  - `parse_errors`：解析错误数
  - `mq_sent`：MQ 发送数
  - `mq_send_errors`：MQ 发送错误数
  - `disk_buffer_writes`：磁盘缓冲写入数

- **ConsumerMetrics**：消费层指标
  - `messages_consumed`：消费消息数
  - `messages_processed`：处理成功数
  - `messages_failed`：处理失败数
  - `dead_letter_count`：死信消息数

- **PushMetrics**：推送层指标
  - `connections_total`：总连接数
  - `connections_active`：活跃连接数
  - `messages_pushed`：推送消息数
  - `alerts_pushed`：报警推送数
  - `push_errors`：推送错误数

### 2.2 健康检查 HTTP 接口

**文件**：
- `monitor-common/src/metrics/health_server.rs`
- `monitor-access/src/metrics.rs`
- `monitor-push/src/metrics.rs`

#### HealthServer 特性
- 基于 Tokio TcpListener 的轻量级 HTTP 服务器
- 无额外依赖，纯 Rust 实现
- 异步非阻塞

#### 接口定义

| 端点 | 方法 | 说明 |
|------|------|------|
| `/health` | GET | 健康检查，返回 200 表示服务正常 |
| `/metrics` | GET | 指标暴露，Prometheus 格式 |

#### 健康状态
- **status**：`healthy` / `unhealthy`
- **uptime**：运行时长
- **service**：服务名称
- **version**：版本号

### 2.3 日志规范

#### 日志框架
- 基于 `tracing` + `tracing-subscriber`
- 支持结构化日志（JSON 格式）
- 支持环境变量配置日志级别（`RUST_LOG`）

#### 日志级别
- **ERROR**：错误，需要立即处理
- **WARN**：警告，需要关注
- **INFO**：信息，正常运行状态
- **DEBUG**：调试，开发阶段使用
- **TRACE**：追踪，详细调试

#### 日志字段规范
- 所有日志使用结构化字段
- 必带字段：`target`（模块名）
- 设备相关：`bed_no`, `device_ip`, `vendor`
- 错误相关：`error`（错误信息）
- 性能相关：`count`, `duration`, `latency`

### 2.4 全链路集成验证工具

**文件**：`monitor-test/src/simulator.rs`

#### HL7 设备模拟器
- 模拟 1-8 号床位监护仪
- 支持迈瑞/科曼两种厂商格式
- 持续发送三类数据：
  - **波形数据**：ECG II 导联，500Hz 采样率
  - **生命体征**：心率、血氧、呼吸、血压
  - **报警事件**：心动过速等，支持开始/结束

#### 使用方式
```bash
# 编译
cargo build -p monitor-test --bin simulator

# 运行（模拟 4 个床位，心率 75，运行 60 秒）
cargo run --bin simulator -- --beds 4 --hr 75 --duration 60

# 参数说明
--host              目标服务器地址（默认 127.0.0.1）
--port              目标端口（默认 9100）
--beds              模拟床位数（默认 4）
--hr                心率基准值（默认 75）
--wave_interval_ms  波形发送间隔毫秒（默认 1000）
--vital_interval_secs 体征发送间隔秒（默认 5）
--duration          运行时长秒，0=无限（默认 0）
--vendor            设备厂商 mindray/comen（默认 mindray）
```

#### 波形生成算法
- 基于正弦波组合的简化 ECG 模型
- P波、QRS波、T波 分段模拟
- 加入基线漂移和随机噪声
- 心率可配置，自动调整波形频率
